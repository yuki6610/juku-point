# 全画面UI/UXの整理（2026-09-14）

Figma: https://www.figma.com/design/LmchG3UninV5f3SvpqefxK

## 方針

| 役割 | 主な端末 | 先に見せる情報 | 操作の中心 |
| --- | --- | --- | --- |
| 管理者 | PC | 今日の未入力、検索・絞り込み、一覧と詳細 | 生徒・日付の切替、記録編集 |
| 講師 | スマホ | 今日の担当生徒、入力済み・未入力 | 生徒を1タップで選択し、出席→宿題→テスト→保存 |
| 生徒 | スマホ | 今日できること、成果、宿題 | 学習開始、必要なページへの短い導線 |
| 保護者 | スマホ | 要対応、最近の授業、宿題・テスト | 内容を理解して確認、必要時のみ詳細へ |

共通にするのはブランドの青紫、基本書体、余白・フォーカス表示、状態色。塾側は青を主にした密度のある作業画面、顧客側は明るい面と短い文章で落ち着いて読める画面に分けた。管理者と講師は保存API、記録形式、権限チェックを変更していない。

## 調査対象と主な改善点

- 管理者: ダッシュボード、学習記録・出欠、講習、教室設定、生徒管理、生徒メモ、成績、ポイント、自習、景品のルートとナビゲーション、主要CSSを確認。ダッシュボードの大きなプレビュー操作、長い横並び生徒リスト、全画面再読み込みの移動、タブの高さが作業効率を下げていた。
- 講師: 当日の生徒一覧から入力・保存までを確認。生徒選択のプルダウン操作と長い縦スクロールがスマホで負担になるため、担当生徒をタップできる一覧にした。
- 生徒: ホーム、学習、自習、宿題、成績、ポイント、ランキング、景品、ガチャ、夏期イベント、生活態度、設定、使い方のルートとCSSを確認。ページごとの背景・文字密度が揃わず、宿題ページだけカードの視認性が弱かった。
- 保護者: ホーム、授業・宿題、学期レポート、成績提出、カレンダー、お知らせ・PDF、ログインを確認。最近の授業の要点を読むには長い授業履歴へ進む必要があった。
- 共通: 画面拡大を禁止するviewport設定は読みやすさを損なうため解除。生徒メニューが他の役割の画面でもプロフィール取得していたため、不要な読み込みを止めた。

## 実装した優先範囲

1. 管理者のメニュー検索、軽い画面遷移、ダッシュボードの圧縮。
2. 学習記録のPC二列表示（生徒一覧と編集欄）、保存前の切替警告。
3. 講師の当日生徒タップ選択とスマホ下部保存操作。
4. 保護者の直近授業サマリー、要対応・詳細導線の視認性。
5. 生徒の共通背景、宿題カード、ホーム統計、下部メニューの統一。
6. 管理者の成績・自習・景品・生徒管理に共通のタブ／境界線・操作色。

## 検証範囲

既存の自動テスト、ビルド、各役割の読み取り表示を確認する。データ構造やFirestoreルールはこのUI変更では更新しない。実データの保存操作はテスト用データ以外に行わない。
