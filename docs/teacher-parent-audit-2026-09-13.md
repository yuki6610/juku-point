# 管理者・講師・保護者の連携確認

調査・修正日: 2026-09-13。既存データの削除、一括変換、本番の生徒記録へのテスト入力は実施していません。

## 確認できた問題と修正

|対象|問題|対応|
|---|---|---|
|保護者の授業履歴|本番でドキュメントID降順クエリのインデックスエラーを確認。初回読み込み全体も失敗していた|学期内のID範囲で取得してサーバーで並べ替え。履歴・レポート・お知らせを独立して読み込む|
|過去の宿題|古い履歴ページに宿題が付かない。公開コピーが古い場合に訂正結果が欠落|履歴の取得位置に合わせて宿題も取得し、許可した公開項目だけ旧・新保存先から統合|
|出欠訂正|古い公開データが管理者による訂正・取消と競合|更新日時と明示された取消を考慮して共通・旧・公開記録を統合|
|講師からの保存|管理者グラフ用の学期集計が更新されない|共通保存APIのトランザクション内で学期集計も更新|
|講師フォーム|生徒変更時に入力値が残る、0点が失われる、保存済み宿題の訂正・再試行に問題|読み込み競合防止、全項目の復元、アカウント別下書き、宿題IDと版管理、保存前検証を追加|
|宿題判定|単語テストの番号範囲も提出判定対象になる。欠席時も全項目を要求|単語範囲は点数管理のまま提出判定から除外。欠席は次回確認扱い|
|保護者公開範囲|提出状況APIが他の生徒の提出状況も返す|紐づいた中学生の提出状況だけを取得|
|データアクセス|停止保護者や内部記録・対象限定資料の直接取得経路|保護者有効状態を確認。内部学習記録・対象限定資料設定への直接アクセスを制限するRulesに変更|
|保護者の成績入力|空欄が0点になる。連続送信で重複し得る|空欄・範囲・整数を検証し、既存成績確認をトランザクションへ移動|
|保護者表示|学期切替中の前学期データ、取得失敗時の誤った未提出表示、出席率の分母に欠席がない|読込中の旧集計を消去し、失敗と未提出を区別。出席率の分母に欠席を含める|

## UI改善

- 講師: 選択中の生徒・授業日を明示、保存中の操作を制限、教材行の削除、スマートフォンの入力サイズ・余白を調整。
- 保護者: 年間カレンダーを月単位で切替、確認済み宿題を折りたたみ、後日完了を要対応一覧から除外。
- 授業日ごとの履歴にも宿題の個別結果と旧形式の提出結果を表示。
- お知らせは表示しただけで既読にせず、明示的な既読操作に変更。
- 管理者の保護者プレビューは生徒選択を閉じた状態を基本とする。
